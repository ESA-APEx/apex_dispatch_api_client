## [0.7.2] - 2026-06-04

### Added

- Generated Python client for the APEx Dispatch API from the OpenAPI schema.
- Typed request and response models for APEx Dispatch resources, jobs, upscaling
  tasks, STAC collections, and error payloads.
- Synchronous and asynchronous endpoint helpers backed by configurable `httpx`
  clients.
- MkDocs documentation with tutorials, how-to guides, reference pages, and
  generated-client explanations.
- Hatch environments for tests, type checks, linting, formatting, and
  documentation builds.
